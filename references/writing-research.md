# Writing, research, and thesis mode

## Scope

Use for compositions, reading reports, case analyses, survey reports, course papers, literature reviews, proposals, theses, experimental papers, English academic writing, revisions, translations, reviewer replies, and presentation scripts.

## Build order

1. Restate the research question and audience in one sentence.
2. Define the claim, scope, concepts, and exclusions. For a literature review, define the search boundary and comparison dimensions.
3. Build an outline where each section has a job, evidence, and a transition reason. Use the course rubric as the acceptance test.
4. Draft from evidence: claim → support → interpretation → limitation/qualification. Keep description separate from analysis.
5. Audit that every strong claim has support, every citation exists and says what the prose claims, and every conclusion answers the question.
6. Revise at three levels: argument/structure, paragraph logic, then sentence/style. Preserve the writer's meaning and voice.

## Common shapes

- **Essay/report:** question → context → thesis → organized evidence → counterpoint/limits → conclusion.
- **Research paper:** abstract → introduction/gap/question → related work → method → results → discussion → limits → conclusion.
- **Experimental paper:** purpose/hypothesis → materials and reproducible method → raw/processed data → uncertainty → result → interpretation.
- **Thesis:** problem and contribution → literature and gap → method/design → chapters/results → synthesis and limits.

## Citation discipline

Keep a source table with stable identifiers (DOI, ISBN, URL, database ID) and access dates. Do not invent page numbers. Label a source as primary, official, peer-reviewed, textbook, class material, or secondary. When browsing is unavailable, use supplied sources and mark the literature search incomplete. For supplied-only tasks, do not add outside claims, quotations or references.

## Natural style

Use concrete verbs, precise nouns, varied but controlled sentence lengths, and transitions that state the logical relation. Remove vague intensifiers, repeated conclusions, inflated claims, and stock filler. If the user provides their own sample, extract its sentence length, phrasing, vocabulary, structure and degree of formality; preserve those choices without inventing experiences or copying irrelevant passages. “Humanize” means clarity and authentic voice, not evading an evaluator.
