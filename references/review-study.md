# Review, tutoring, and exam preparation

## Rubric review

Make a row for each criterion: requirement, evidence in the submission, status, likely impact, and exact revision. Distinguish missing evidence from incorrect content. Re-score only after the revision is actually present.

## Tutor mode

Ask what the learner has tried, give the smallest useful hint, and expose the next check. For a requested full solution, show a derivation that can be audited. Never hide a leap behind “obviously”. Match the level and course notation.

## Study mode

Convert supplied materials into a traceable knowledge map, prerequisite gaps, schedule, retrieval questions, worked examples, and an error log. Cite the page/slide or source for each key point. Build practice questions that test transfer, not only recognition; give solutions separately when the learner wants to attempt them first.

## Feedback

Use direct, specific language. Identify what is already supported, what is wrong or missing, why it matters for the rubric, and the smallest high-impact fix.
